# HomeServer Backup

HomeServer Backup is a personal backup application used by its
owner to store encrypted backups in Google Drive using restic
and rclone.

Backup contents are encrypted locally by restic before upload.
The application requests Google Drive access to files it creates
or that the user explicitly authorizes for the application.

This application is for personal use and is not a public service.
